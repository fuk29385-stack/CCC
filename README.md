# College Control Center

College Control Center — адаптивный планировщик задач, предметов и расписания для студентов колледжа. Интерфейс на русском языке, данные хранятся в браузере пользователя и не отправляются на сервер.

Сайт: [https://fuk29385-stack.github.io/CCC/](https://fuk29385-stack.github.io/CCC/)

## Возможности

- Календарь с задачами и отметками важных дедлайнов.
- Создание, редактирование, удаление и поиск задач; цветные теги и фильтры по дате, статусу, предмету и тегу.
- Список задач, канбан-доска со статусами и календарный вид; анимация выполнения и конфетти.
- Таймер фокусировки с настройкой длительности, быстрыми пресетами и привязкой к задаче или категории; состояние таймера сохраняется между перезагрузками, а по завершении задача получает выбранный статус.
- Статистика выполненных и просроченных задач и ближайший дедлайн.
- Предметы с цветными метками и недельное расписание пар.
- Экспорт и импорт резервной копии в формате JSON.
- Светлая и тёмная темы, напоминания и установка как PWA.
- Адаптивная вёрстка для телефонов, планшетов и компьютеров.

Задачи (включая теги), предметы, расписание, таймер и выбранная тема сохраняются в `localStorage` этого браузера. Они не синхронизируются между устройствами. Экспортируйте резервную копию, чтобы перенести данные.

## Как запустить

Это статический сайт — сборка и установка зависимостей не нужны.

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

Для проверки Service Worker и установки PWA запустите локальный HTTP-сервер из папки проекта, например:

```powershell
python -m http.server 8000
```

Откройте [http://localhost:8000/](http://localhost:8000/). На GitHub Pages приложение опубликовано по адресу выше; ресурсы подключаются относительными путями, поэтому работают в подпапке `/CCC/`.

## Форма обратной связи

Перед отправкой сайта замените значение `CONTACT_ACCESS_KEY` в начале `app.js` на ключ проекта Web3Forms. Форма отправляет имя, email, тему и сообщение непосредственно в Web3Forms; повторная отправка ограничена интервалом в 30 секунд.
